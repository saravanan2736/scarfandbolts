Privacy Policy

Last updated: 26 November 2026

This policy describes the "Leo Factory" application operated by Scarf and Bolts (the "App"). The App is a private, internal publishing tool used only by the owner of the Scarf and Bolts YouTube channel to upload that channel's own videos.

YouTube API Services

The App uses YouTube API Services. By using the App's YouTube features you agree to be bound by the YouTube Terms of Service. Google's handling of your data is described in the Google Privacy Policy.

What the App accesses

With the channel owner's permission (Google OAuth 2.0), the App:

  • uploads videos to the owner's own channel (videos.insert), and
  • reads the connected channel's name once at sign-in (channels.list) to confirm the correct channel is connected.

The App does not access, collect, store or share any information about viewers, other YouTube users or members of the public. It does not use cookies or analytics.

What is stored, and where

  • The channel owner's OAuth refresh token, stored encrypted in the owner's private GitHub repository secrets, used only to upload the owner's videos.
  • The YouTube video ID of each video the App uploads, so the same video is not uploaded twice.

No other YouTube API data is stored. Data is never sold, shared or transferred to anyone.

Deleting data and revoking access

Access can be revoked at any time from the Google security settings page. After revocation, the stored token stops working and is deleted from the repository secrets within 7 days. Stored video IDs can be deleted at any time on request.

Children

The App does not collect any personal information from anyone, including children.

Changes

Any change to this policy will be posted on this page with a new "last updated" date.

Contact
